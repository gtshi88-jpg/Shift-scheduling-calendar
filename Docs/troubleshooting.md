# トラブルシューティング

## 1. ログインできない

### 症状

- ユーザー名 / パスワードが正しいはずなのにログイン失敗する

### 確認ポイント

- `.env.local` の認証系環境変数が意図通りか
- 変更後に `npm run dev` を再起動したか
- Admin / Member を取り違えていないか

### 対処

1. `.env.local` の値を再確認
2. サーバー再起動
3. ブラウザのセッションをクリアして再ログイン

## 2. データが保存されない / 反映されない

### 症状

- シフト更新後に再読み込みすると元に戻る

### 確認ポイント

- `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` が設定されているか
- Supabase 側にテーブルが作成済みか（`supabase/schema.sql` 適用済みか）
- ネットワークエラーや API エラーが出ていないか

### 対処

1. `.env.local` を見直す
2. スキーマ適用状況を確認
3. 開発サーバーを再起動して再試行

## 3. 画面が正しく表示されない

### 症状

- UI が崩れる / 期待した内容が表示されない

### 確認ポイント

- ブラウザキャッシュの影響がないか
- 最近の変更で `app/` 配下のコンポーネントを更新していないか
- コンソールにエラーが出ていないか

### 対処

1. ハードリロード
2. 変更差分を確認
3. 問題箇所を最小再現して切り分ける
