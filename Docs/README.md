# Calendar プロジェクト備忘録

この `Docs` は、運用手順・仕様メモ・障害対応ログを整理して残すためのドキュメント置き場です。

## ドキュメント一覧

- [セットアップ手順](./setup.md)
- [認証仕様メモ](./auth.md)
- [Supabase 運用メモ](./supabase.md)
- [トラブルシューティング](./troubleshooting.md)
- [変更ログ](./change-log.md)

## 使い方ルール（簡易）

- 1トピック1ファイルで追記する
- 「手順」と「理由」をセットで書く
- 更新時は `change-log.md` に要点を残す
- 個人情報・秘密情報（実パスワード、キー本体）は記載しない
